## What lives here

| Size | Where it actually lives |
|---|---|
| **< 5 MB** | Committed to this directory |
| **≥ 5 MB** | A GitHub Release asset on the **student** repo. `make data` downloads it into here. Only the URL + sha256 are in git |
| torchvision / Hugging Face datasets | Not here at all — their own libraries download and cache them |

Everything is declared in [`../datasets.yaml`](../datasets.yaml) first. A file in this directory with
no registry entry is a bug: no lab can reach it, because notebooks never contain paths.

## Commands

```bash
make data           # download everything missing
make data-verify    # re-hash every cached file against the registry
python ../tools/fetch_datasets.py --only telco_churn
python ../tools/fetch_datasets.py --update-hashes   # fill in sha256/size after adding a file
```

## data_cache vs artefacts

| | `data_cache/` | a lab's `artefacts/` |
|---|---|---|
| What | Raw inputs, shared across labs | Output a lab produced |
| Committed | Yes (small files) | Never — gitignored |
| Lifetime | The whole course | Regenerated by whoever runs the lab |

Reference copies of artefacts a *later* lab consumes go in [`../solutions_cache/`](../solutions_cache),
not here.

Full rules: [`../../docs/Data_Guide.md`](../../docs/Data_Guide.md).
