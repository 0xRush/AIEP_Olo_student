# solutions_cache/

Reference copies of the artefacts labs produce, so a student who missed a day is not blocked the next
day.

# مجلّد solutions_cache

نسخ مرجعية من المخرجات التي تنتجها المعامل، حتى لا يتعطّل الطالب الذي فاته يوم عن متابعة اليوم التالي.

</div>

## How it is used

`aiep.data.load_artefact` looks in the notebook's own `artefacts/` first, then falls back here:

```python
from aiep.data import load_artefact

features = load_artefact("features.parquet")
# ./artefacts/features.parquet  →  shared/solutions_cache/features.parquet
```

When the fallback is used, the student sees a bilingual note saying so — they should know they are
working from the reference copy, not their own output.

## The rule

**Providing a reference copy here is mandatory for every artefact a later lab consumes.** Record what
each lab produces and consumes in that week's `Lab_Specs.md`. A lab that hard-fails because yesterday's
output is missing is a broken lab.

Files here are committed (keep them small — sample if needed) and are the *instructor's* correct
output, generated by running the `_solution` notebook.
